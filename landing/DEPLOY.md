# Deploy

**Use the `hostinger-site/` folder at the repo root** (not the repo root itself).

1. Run `./landing/build-for-hostinger.sh` after any change to `landing/`
2. Open `hostinger-site/`, select all files, upload to Hostinger `public_html/`
3. Read `UPLOAD-TO-HOSTINGER.txt` in that folder for details
